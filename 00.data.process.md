## **Fastq process**

### Assay for Transposase-Accessible Chromatin using sequencing software install

```shell
## websit:https://github.com/MGI-tech-bioinformatics/DNBelab_C_Series_HT_scRNA-analysis-software

## download
wget -O dnbc4tools2.1.3.tar.gz "https://ftp.cngb.org/pub/CNSA/data5/CNP0006367/Single_Cell/CSE0000448/dnbc4tools2.1.3.tar.gz"

## install
tar -xzvf dnbc4tools2.1.3.tar.gz
```

### Process.slurm

```shell
#SBATCH -J process_data
#SBATCH -o output_%J
#SBATCH -e errput_%J
#SBATCH -N 1
#SBATCH -n 1
#SBATCH -c 10
source activate ES
fastq1=$1
fastq2=$2
dnbc4tools atac run \
    --fastq1 ${fastq1} \
    --fastq2 ${fastq2} \
    --genomeDir /database/scATAC/Mus_musculus/mm10 \
    --name test --threads 10
```

### **Run the script**

```shell
sbatch process.slurm fastq_R1.gz fastq_R2.gz
```

##  **Creating Arrow Files**

```R
library(ArchR)

args = commandArgs(T)
file = args[1]
print(file)
names(file) = gsub(".bed.gz","",file)

print(Sys.time())
print("start")


ArrowFiles <- createArrowFiles(
  inputFiles = file,
  sampleNames = names(file),
  filterTSS = 4, #Dont set this too high because you can always increase later
  filterFrags = 1000,
  addTileMat = T,
  addGeneScoreMat = T
)
print(ArrowFiles)
print("end_archr")
print(Sys.time())

```
